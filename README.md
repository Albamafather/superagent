# 🍅 番茄钟 · 待办

纯前端番茄钟 + 个人待办管理应用，无任何构建步骤与运行时依赖。

## 功能

### 待办清单
- 添加、编辑（点击文字）、完成、删除待办
- 筛选：全部 / 进行中 / 已完成，一键清除已完成
- 待办随 localStorage 持久化，刷新页面不丢失
- 🎯 将专注与待办关联：每完成一个专注番茄，自动为该待办累计 🍅

### 番茄钟
- **专注 25 分钟** → **短休息 5 分钟**，每完成 4 轮专注后进入 **长休息 15 分钟**
- 开始 / 暂停、重置、跳过当前会话
- 点击模式按钮可直接切换 专注 / 短休息 / 长休息
- 每个会话结束后播放提示音，浏览器标签页标题实时显示倒计时
- 统计已完成专注次数与完整循环数
- 计时基于墙钟时间，标签页被浏览器节流也不会丢失时长

## 使用

```bash
npx serve .          # 或任意静态文件服务器
# 打开 http://localhost:3000
```

也可以直接用浏览器打开 `index.html`。

## 测试

计时与待办逻辑均为纯状态机（`js/timer.js`、`js/todos.js`），使用 Node 内置测试运行器：

```bash
npm test
```
